# MTCS Sans · MTCS Serif

**MTCS**는 Modern Type for Clear Sentences(또렷한 문장을 위한 현대 활자)의 줄임말입니다.

문서와 발표를 위한 고딕, 신문체 명조 무료 한글 폰트입니다.

- MTCS Sans: Noto Sans KR(© Adobe)을 바탕으로 수정한 고딕
- MTCS Serif: Noto Serif KR(© Adobe)을 바탕으로 획 대비를 높인 신문체 명조
- 굵기: Light, Regular, Medium, SemiBold, Bold, ExtraBold · 형식: TTF · 버전 1.100
- 라이선스: SIL Open Font License 1.1 ([OFL.txt](OFL.txt))
- 수정: 이윤재

폰트 파일은 `fonts/` 폴더에 있습니다.

웹폰트로 쓰려면 HTML의 head에 아래 한 줄을 넣습니다.

```html
<link rel="stylesheet" href="https://ssayuz.github.io/mtcs/mtcs.css">
```
